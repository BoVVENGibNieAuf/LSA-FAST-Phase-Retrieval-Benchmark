# FAST support / 芯模尾场 / 检测光路独立分支

分支：`research/fast-support-optics`。基点 `4605272`，保留主线全部历史结果。此处为可运行研究分支，**尚无新增 MATLAB 数值结果**。

## 核对结论

1. **Support 值得修改，但“大”尚不是已证实病因。** 原作者 `legacy_fast/main.m` 对 `amp_facet_ref` 做 `imbinarize(...,0.02)`，随后 `imclose(...,strel('disk',10))`。补充图 S2(d,e)说明 mask 来自参考端面幅值图，代表纤束形态。它不等价于逐芯硬圆，也不保证比任意外圆盘更小。主线半径29 μm相对物理端面26 μm，面积比约1.244，即多24.4%；是否影响恢复须实测。缩小支持域可能排除尾场，必须同时报告参考/样品漏能和全场误差。
2. **当前模型已经有芯外高斯尾部。** `fast_mcf_field` 为 `exp(-r²/w²)`，原w=0.9 μm±10%，截在3w，并非在1 μm芯半径硬切。孤立高斯3w外功率比例为 exp(-18)，约1.52e-8；只把3w延到5w通常不会带来明显改变。视觉上的“芯间过分清楚”还涉及w/芯距、随机相位干涉、有限NA和显示动态范围，不能靠额外加背景场伪造。
3. **原文检测端确实有镜头。** FAST Materials and methods：10×、NA0.25物镜与f=200 mm消色差透镜组成4f系统，UI-3482LE相机，线偏振检测。无透镜主要指探头/样品端。补充材料 Fig.S3 用同视场降采样，并指出充分采样时算法表现相近，严重欠采样时难收敛。因此提高像素数不是必然提高算法性能。

## 实现与对照

沿用现有 MATLAB、Image Processing Toolbox、FFT 和四种方法的已验证框架；未另建Python重建实现。冻结 `legacy_fast/`。新增算子仅在 `src/branch/`，现有主线求解器不改。

采用物方等效理想相干中继：`A u = IFFT{ pupil(NA) * H_AS(z_object) * FFT(u) }`，传感器读数为每个像素覆盖的细网格 `sum(|Au|²)`。M用于物方/相机像素单位转换；省略的共同中继幅值常数并入曝光。此为理想、无像差、远心等效模型，不是逐镜片光线追迹，也没有确定作者公开数据的完整像/物方坐标映射。

有限NA或不可传播频率存在时，A*不是逆A。分支HIO/ER/RAAR使用 `u+A*(P_block(Au)-Au)` 作为数据一致性步，再沿用支持域更新；**它是广义一致性迭代，不声称严格的可逆幅值投影或原文FAST迭代**。L-BFGS用积分像素幅值平方误差及其精确伴随梯度，未改成Poisson似然。四方法比较须带此限定。

每布局10个无噪声条件：

| 条件 | 相比上一个合适控制组改变 |
|---|---|
| control | 大圆support，w=.9，截3w，无有限NA，bin2；分支新网格控制，不冒充旧数据 |
| support | 相同场与相机，仅改为参考阈值+闭运算support |
| threshold_only | 取消闭运算；机制消融，不称为作者mask |
| tails | 对support条件仅把3w改为5w |
| relay | 对tails条件仅加入NA0.25 |
| mode12 / mode15 | 对relay仅改w到1.2/1.5 μm；support规则保持相同，掩模随独立参考重新生成 |
| pixels1 / pixels4 / pixels5 | 对relay仅改像素积分尺寸，视场和重建网格不变 |

0.02阈值明确施加于峰值归一化**幅值**，不是强度。原作者阈值则用于其存储幅值标度，故本分支是规则对齐而非字节级复制。闭运算半径取10×2.2/10=2.2 μm，再换算细网格像素；这是基于10×的条件性尺度映射，不应直接把旧29 μm圆改成随意小圆。

附加噪声条件仅选support、relay、pixels1，各3个种子。以无孔径空白参考细像素平均10个检测电子确定共同入射曝光。相同光学场先在细网格生成同一Poisson计数，再合并像素；像素多不会凭空增加总光子数。有限NA损失不额外补光。1/2/4/5倍像素对应相机2.2/4.4/8.8/11 μm，物方0.22/0.44/0.88/1.1 μm；主线0.5 μm并非当然欠采样。

合计 `2布局 × (10无噪声 + 3条件×3种子) × 4方法 = 152` 次求解，每次最多200传播调用。CPU double，单次求解120秒软上限，整个调用1800秒软上限；成功结果带哈希收据，可续跑，不并发GPU任务。

## 验证与输出

启动前自动执行 MATLAB 测试：伴随内积、积分像素目标方向导数、像素功率守恒、零场投影、无NA/bin1极限下四方法与原求解器数值一致性。未通过不进入实验。

`relay`另外生成双细网格检测强度，报告相对差异，检查数值采样偏差；当前求解实验主体为同网格模型，不能把它说成充分独立的现实系统验证。该差异若超过预设工程参考5%，先审查网格，再解释算法排序，不按测试真值调参。

报告每轮：固定参考ROI复场NRMSE、相位RMSE、全场NRMSE、测量残差、实际传播数和耗时；分开保存support面积、漏能、NA通量、总光子数。最佳值只作**回顾性真值诊断**，不会给求解器早停。物理真场与NA滤波后的端面图分别显示，避免混为一谈。

入口 `START_SUPPORT_OPTICS.cmd`；结果 `runs/support_optics_v1/`；评分真值 `evaluation_only/support_optics_v1/`。曲线、MAT终态、逐条件模型图、迭代图、`retrospective_best.csv`均由真实MATLAB运行生成，未填预期结果。若上次意外终止留下RUN.lock，先确认进程已退出再处理，不自动删锁。
