# MCF 输出场模型与测试协议

## 1. 文献结论

**MCF 端面的光场是一组局域纤芯模式的相干叠加。** 在端面附近，振幅呈离散亮芯，包层幅值较低；每个纤芯携带自己的光程相位。传播到检测面，各芯衍射光相互干涉，形成散斑。样品改变输入耦合系数；静态光纤的芯位置、模式与传输相位在参考／样品测量之间保持一致。

|来源|已核对的内容|对本测试的作用|
|---|---|---|
|[Sun et al., FAST, 2022](https://www.nature.com/articles/s41377-022-00898-2)，Methods / Multi-core fiber bundle、Experimental setup；Results / Image reconstruction|FIGH-350S，40 cm，约 10000 芯，束径 350 μm，平均芯径 2 μm、间距 3.2 μm；532 nm；检测端检偏；不同芯的光程相位|采用波长与平均芯间距；建立固定逐芯复传输模型|
|[Kogan et al., Optics Letters 42, 647–650 (2017)](https://opg.optica.org/ol/abstract.cfm?uri=ol-42-3-647)，已读取摘要|需恢复各芯相对相位；无噪声情形下无序布局对相位恢复有利；实验验证至同时照明 10 芯|位置扰动与逐芯相位有建模依据；本次扰动分布为指定仿真假设|
|[Sun et al., arXiv:2312.07102](https://arxiv.org/html/2312.07102)，已读取正文|输入相位经 MCF 的固有芯间光程差调制，在另一端记录散斑；实验配对相位／散斑数据|再次确认输入相位—光纤传输—检测散斑的链路|

代码方案预检：沿用项目现有 MATLAB HIO／ER 支持域更新与振幅投影模块。通用强度型 fiber-bundle 图像采样模拟器不能提供这里所需的逐芯复相位传播，故新增小型标量模型模块。

## 2. 本次实现

在单偏振、每芯一个主导空间模式、对角传输近似下：

\[
\psi_j(\mathbf r)=\sqrt{2/\pi}\,w_j^{-1}
 \exp[-|\mathbf r-\mathbf r_j|^2/w_j^2],\qquad
c_j=\int U_\mathrm{in}(\mathbf r)\psi_j^*(\mathbf r)\,d^2r,
\]
\[
U_\mathrm{out}(\mathbf r)=\sum_j g_j e^{i\theta_j}c_j\psi_j(\mathbf r).
\]

- 高斯模式连续归一化满足 `integral(abs(psi)^2)=1`；计算截断在 3 个模式半径。
- `w` 是振幅的 1/e 半径，同时是强度的 1/e² 半径。
- 样品设于输入端面，`U_in = amplitude * exp(i*phase)`；通过面积积分计算耦合，跨越一个芯的相位变化也会影响耦合振幅。
- 参考用平面波入射。参考与样品共用同一 `g_j, theta_j, r_j, w_j`。
- 模型不对低亮度包层强行赋予可评价相位。相位评分 ROI 由参考振幅阈值一次确定。

## 3. 数据生成和相机

使用标准 FFT 频率坐标的角谱传播，去除统一的轴向载波相位：

`H = exp(i * z * (sqrt(k²-kx²-ky²)-k))`。

生成端排除倏逝频率；当前粗网格的全部离散频率均为传播波，因此粗网格往返算子为酉算子。该实现单独命名，原 `legacy_fast/prop.m` 保持原样。

在细网格上算检测强度，对每 2×2 子像素取强度平均：

`I_pixel = mean(abs(U_detector_fine).^2)`。

清洁条件测量为 `sqrt(I_pixel)`。含噪声条件取 `Poisson(exposure*I_pixel) + Gaussian(0,1)`，截断负读数后转换回振幅。曝光仅由空白参考确定，所有样品沿用。Poisson 采样采用精确乘积法，无额外 Statistics Toolbox 依赖。

生成审计：

- 参考图用 2×、4×两种细网格生成，振幅差异阈值 2%。
- 检查检测图外侧 4 像素边带能量比例，阈值 0.5%，用于提示有限视场风险。
- 审计通过才进入重建；失败信息与已生成文件保留。
- 这两项检查分别监控采样精度和边界能量。后续大传播距离还需额外视场加倍收敛检查。

## 4. 公平比较与结果解释

固定 blank／step／smooth／mixed 四种入射样品，clean／shot_read 两种相机条件，共 8 个测量案例。几何种子 20261003，噪声种子 3102026 加场景索引。HIO 与 ER 对同一个案例读取完全相同的输入文件。

|项目|共同设置|
|---|---|
|校准／初始化|已知合成参考复光场，明确作为本阶段的理想校准条件|
|支持域|半径 26 μm 的共同外轮廓；求解器只得到该轮廓|
|求解预算|每方法每案例 40 次迭代、80 次传播；beta=0.2|
|检查点|10／20／30／40；报告固定第 40 次结果|
|评分|每检查点一次额外传播；ZERO 与 TRUTH_DIAGNOSTIC 各一次|
|计算资源|单任务 CPU double；600 秒软时限，固定数组尺寸|
|运行保留|独立 run_id、配置、代码哈希、数据哈希、检查点、失败记录|

指标定义：

- **测量残差**：粗网格预测检测振幅与实测振幅之差的 NRMSE。
- **全场误差**：全图复场 NRMSE，包含芯内、包层及支持域外的物理输出；评分时只消除一个全局相位。
- **亮芯相位误差**：固定参考 ROI 内的包裹相位差 RMS，单位 rad；低于阈值的恢复相位记为无效。
- **TRUTH_DIAGNOSTIC**：真值经过粗网格测量模型后的残差，用于量化像素积分、离散化与噪声的影响；只由评分层读取。

相位结果图展示恢复输出相位减去共同参考相位，真值图采用同样定义。它表示纤芯模式耦合后的相位变化。生成模型、相机、求解器与评分的职责分别保留在代码中。

## 5. 运行与产物

双击项目根目录 **START_MCF_PILOT.cmd**，或在 MATLAB 中执行：

```matlab
setup_project;
run_fast_mcf_pilot;
```

结果写入 `runs/pilot/mcf_<timestamp>/`：

- `status.json`、`tests.json`、`generation_audit.json`、`config.json`、`provenance.json`；
- `MCF_model.png`：实际生成的端面振幅、随机参考相位、检测强度及芯位置；
- 各案例的 `field_comparison.png`、`metric_curves.png` 和 HIO／ER 检查点；
- `metrics.csv/json`、`REPORT.md`；
- 真值和光纤生成参数独立存入 `evaluation_only/<run_id>/`，求解函数不读取该目录。

数值运行状态以 `status.json` 为准。源码静态检查与 MATLAB 数值验收分别记录。
